# Python Battle Game

A simple console-based battle game made with Python.

## Features

- Attack system
- Critical hits
- Miss chance
- Defense system
- Strength potion
- Health potion
- Temporary potion effects
- Death Dice mechanic
- Health tracking
- Randomized combat outcomes
- Colorized terminal output

## Requirements

- Python 3
- colorama

## Installation

Install the required library:

```bash
pip install colorama
